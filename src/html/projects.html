University Projects

01

Surgical Robot Simulator

Interactive 3D simulation of an operating room with an articulated surgical robotic arm inspired by the Da Vinci system. Built a custom forward/inverse kinematics engine (CCD), real-time collision detection, and a fully scripted animated doctor character — no imported animation clips, all hand-coded in Three.js. Team project for Interactive Graphics.

JavaScript Three.js WebGL
↗ github ↗ demo
02

Bachelor's Thesis Project

A Web API built with ASP.NET Core during my internship at ACK: users upload a photo and receive a detailed AI-generated description. Chains three APIs — Azure Computer Vision for the base caption, Clarifai for object and color recognition, and Groq to synthesize everything into a rich, coherent Italian description — plus a lightweight UI and upload history stored in a database.

C# ASP.NET Core Azure Vision
↗ github
03

Computer Vision Project

A Latent Diffusion Model in PyTorch that generates synthetic dental radiograph patches, conditioned on anatomical annotations (bounding boxes and keypoints) to augment a severely underrepresented periodontal disease class. Compares an unconditioned baseline against the anatomically-guided model through an ablation study and a downstream classification task. Team project for Computer Vision (Prof. Irene Amerini).

Python PyTorch Diffusion Models
↗ github
04

Image Classification

CNN-based perception pipeline for a humanoid soccer robot: classification of what's in view (ball, goalpost, robot...) and regression of where it is in the frame, trained on 8,000+ match images from the SPQRL dataset. Includes a full hyperparameter tuning study across learning rate, batch size, and epochs, plus corrupted-file handling for a robust training pipeline.

Python CNN
↗ github
05

Robot Control

Learns the joint-space control function of a robotic arm without a physical model, approximating inverse kinematics with a Bagging Regressor ensemble of decision trees. Tested and hyperparameter-tuned across three arms of increasing complexity (3, 4, and 6 degrees of freedom), analyzing overfitting and shrinkage-to-the-mean as dimensionality grows.

Python scikit-learn
↗ github
